# Liavesta Cosmetics — corporate website

A bilingual (Turkish/English), responsive brand website for Liavesta Cosmetics, built with plain HTML, CSS and JavaScript.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static web server. No build step or dependencies are required.

## Included

- Responsive, premium editorial-style landing page
- Turkish / English language switcher
- Face care, personal care, home & bath, and aromatic oils categories
- Brand story, manufacturing / quality information, and B2B partnership sections
- Contact form that prepares an email to `info@liavesta.com`
- Reduced-motion support and mobile navigation

## Before launch

- Confirm that `info@liavesta.com` is the correct monitored mailbox, or replace it in `index.html` and `app.js`.
- Connect the contact form to a secure backend or CRM if submissions should be stored or handled without opening the visitor’s email app.
- Replace editorial stock photography with approved Liavesta product, facility and brand photography.
- Confirm product claims, manufacturing capabilities, privacy notice and legal details before publishing.

## Content management

This is a public-facing brand showcase, not a commerce or content-management system. A secure admin panel needs authenticated server-side storage and access control; it should be added when a backend/CMS is selected rather than shipping a client-only, insecure admin screen.
